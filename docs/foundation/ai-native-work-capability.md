# 3. 基础认知

## 它是什么？

我现在研究的并不是单独的“Research Agent”，而是一套更大的能力：

> **AI-native Knowledge Work**

即：

> 一个知识工作者如何利用 AI 完成复杂、开放、信息密集、需要判断和交付的真实任务。

进一步，可以把它理解为：

> **Human → AI → System**

而不是简单的：

> Human → Code。

---

## 为什么出现？

过去，知识工作的瓶颈往往是：

> 找信息慢、整理慢、写作慢、实现慢。

生成式 AI 和 Agent 出现之后，很多“生产”环节的成本急剧下降。

例如 OpenAI 对 Deep Research 的设计已经不是简单的问答，而是让系统进行多步骤研究：理解任务、制定研究计划、检索多个来源、持续研究、综合结果，并生成带引用的结构化报告；用户还可以在过程中查看和调整计划。

Anthropic 的 Research 系统也采用了更明显的 Agentic 研究范式：由 Lead Agent 制定策略并拆分任务，再让多个子 Agent 并行研究不同方向，最后进行综合和引用处理。Anthropic 还特别指出，开放式 Research 的核心难点不仅是搜索，而是 Agent 协调、工具设计、评估、可靠性和成本控制。

这说明一个重要变化：

> **未来的知识工作，不再只是“人学习 AI 工具”，而是“人重新设计自己的工作流程，让 AI 成为工作系统的一部分”。**

---

## 核心原理是什么？

我目前认为最重要的不是“Agent 有几个节点”，而是下面这条链：

> **Problem → Research → Reasoning → Communication → Decision → Delivery → Evaluation → Automation**

其中：

- Problem：定义问题
- Research：寻找信息和证据
- Reasoning：分析与综合
- Communication：组织表达
- Decision：产生建议与行动
- Delivery：形成正式交付物
- Evaluation：验证结果质量
- Automation：把稳定重复的环节交给 Agent / System

这意味着：

> **Agent 应该是工作流程的产物，而不是工作流程的起点。**
