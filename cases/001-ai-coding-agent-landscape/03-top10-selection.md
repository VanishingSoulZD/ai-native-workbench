## 4. Market Assessment

### Strongest independent adoption signals

截至 Phase 3，JetBrains May–July 2026 survey 是最重要的独立市场信号之一：Claude Code 约 39%、GitHub Copilot 约 21%、Codex 约 16%、Cursor 约 12%、OpenCode 约 7%、Google Antigravity 约 6%；JetBrains AI / Junie 合计约 9%。这些是 professional developer survey adoption signals，而不是全球市场份额。[^market1]

这使 Claude Code、Copilot、Codex、Cursor 获得非常强的 market significance confidence，也让 OpenCode 和 Antigravity 的独立市场重要性明显高于只有 vendor/community evidence 的很多候选。

### Vendor-scale evidence

Phase 2 同时记录了：

- Codex：>5M weekly active users；
- GitHub Copilot：4.7M paid subscribers、77K+ organizations；
- Devin：1M+ users、4,000+ enterprise customers；
- Qoder：6M+ users、100K+ businesses；
- Replit：50M+ platform users；
- Factory：hundreds of thousands of developers、enterprise customers、$1.5B valuation。

这些数字均按 Vendor Claim 处理，不能替代独立市场调查。[^phase2]

### China market caveat

中国市场目前没有覆盖 Qoder、TRAE、CodeBuddy、Kimi Code、Qwen Code、Comate 等候选、且具有统一 denominator 的公开独立 market-share survey。因此中国候选不能因为厂商用户数就被机械排到全球前列。[^phase2]

## 5. Capability Assessment

Phase 3 不做完整 architecture dossier，只判断是否存在足以影响 Selection 的 capability evidence。

### Top capability group

**Claude Code / Codex / Cursor / Devin / Antigravity**：均已有完整 repo-level agent loop、tool execution、verification/repair、long-running/background 或 parallelization 等强证据。

### Strong differentiated capability

**Kiro** 的 spec-driven workflow、**Qoder** 的 continuous planning + cloud agents + memory/skills/MCP、**Factory** 的 autonomous Droids、**OpenCode** 的 provider-agnostic open harness 都具有明显 selection-level differentiation。[^phase2]

### Open-source significance

OpenCode、OpenHands、Cline、Qwen Code 等不应仅因为商业规模较小而排除，因为它们是 agent harness、provider abstraction、runtime、skills/subagents 等架构实验的重要载体。[^phase1]

## 8. Final Research Judgment

Composite Score 给出了一个相对清晰的头部结构，但最后十席并不是纯数学问题。

### 8.1 Why Factory enters despite lower market evidence

Factory 的 composite score 低于 TRAE / Kiro 等部分 challengers，但仍进入 Top 10，原因是：

- 其 autonomous enterprise SWE / Droids workflow 具有明显独立范式；
- 企业市场定位与现有 Copilot / Devin 路线并不完全重叠；
- Phase 2 有企业客户、developer adoption、valuation 等 vendor-scale evidence；
- 如果把它排除，Top 10 会过度集中于 consumer/IDE/CLI 产品，而缺少 enterprise autonomous coding agent 代表。

**Divergence**：Composite score 并非最高；Research Judgment 将其列入，是因为 **representative workflow value + enterprise strategic significance** 高于分数本身体现的市场规模。

### 8.2 Why TRAE is Near-miss instead

TRAE 的产品路线很重要，尤其是 AI IDE → TRAE Work / agent workspace；中国市场代表性也很强。[^phase1]

但它与 Cursor / Qoder / Antigravity 的 workflow space 存在较强重叠，同时独立 adoption evidence 仍不足。因此在最后席位竞争中略低于 Factory。

### 8.3 Why Kiro is Near-miss

Kiro 的 spec-driven development 是本研究中最清晰的 workflow innovation 之一，甚至在 Workflow Innovation 上可与 Top 10 相当。

但其绝对 adoption 仍较 Unknown，而且 Amazon Q→Kiro migration 使当前 market baseline 很难与成熟产品直接比较。因此本阶段保留为 Near-miss，而不为了 AWS 战略重要性强行塞入 Top 10。

### 8.4 Why OpenCode enters

OpenCode 的市场规模明显小于 Claude Code/Copilot/Codex，但它具有：

- 2026 独立 survey adoption signal；
- 极大的 OSS ecosystem signal；
- provider-agnostic architecture；
- terminal-native workflow；
- open harness / skills / primary-subagent model。

因此它是本 Case “Market Leaders / Representative Leaders” 中不可缺少的 **open agent harness representative**。

### 8.5 Why Qoder enters

Qoder 是最终 Top 10 中最重要的中国 market/product representative。

原因不是“为了中国市场必须放一个”，而是：

- 有 6M+ users / 100K+ businesses 的 vendor evidence；
- 同时覆盖 IDE、CLI、Cloud Agents；
- 具备 memory、skills、MCP、browser、batch/schedule 等 agent-platform primitives；
- 从 Tongyi Lingma lineage 向全球 Qoder product family 演进；
- 代表中国 AI-native IDE → cloud agent platform 路线。

因此它的 Selection 是 evidence-backed，而不是 geographic quota。

## 9. Final Top 10

> **2026 AI Coding Agent Market Leaders / Representative Leaders — Top 10**

### 1. Claude Code

**Why selected**：最强的独立 adoption signal + 成熟 terminal-first agent loop + 高强度 software-engineering usage evidence。它代表“Coding Agent 从 IDE assistant 变成 repository task executor”的路线。

**Main caveat**：Anthropic proprietary usage data 不能代表整个市场；产品 capability 的最终比较仍需 Phase 4–5。

### 2. Codex

**Why selected**：5M+ weekly active users 的 vendor evidence、16% independent survey signal，以及 App/CLI/IDE/Cloud 一体化 agent system，使其成为 2026 年最重要的 delegated software engineering platform 之一。

**Main caveat**：用户规模为 vendor claim，且不同 Codex surfaces 的 usage denominator 并不统一。

### 3. Cursor

**Why selected**：AI-native IDE 的市场领导者之一，并已向 Cloud Agents、parallel/background execution、remote VM 与 browser/desktop control 扩展，代表 IDE → remote agent workspace。

**Main caveat**：2026-08 的 SpaceX ownership / model-provider dispute 是重要战略变量，需要在 Phase 4 单独分析。

### 4. GitHub Copilot

**Why selected**：开发者生态与企业分发优势极强，并已将 issue/PR、CLI、cloud agent、custom agents、skills、MCP 等组合成 GitHub-native engineering workflow。

**Main caveat**：Copilot 是一个庞大 product family，传统 completion 与 agentic surfaces 的 adoption 很难完全分离。

### 5. Devin

**Why selected**：最典型的 autonomous SWE / agent fleet 代表之一，重点改变的是“人管理多个 agent workstreams”这一 workflow。

**Main caveat**：1M+ users / 4K+ enterprises 主要是 vendor claims，独立 adoption signal 明显弱于头部产品。

### 6. Google Antigravity

**Why selected**：desktop command center、Antigravity CLI、parallel/background agents、MCP、subagents、browser/tool use 构成完整 agent workspace 范式，并有 Google 生态分发能力。

**Main caveat**：相对于成熟产品，其长期市场 adoption 仍处于较早阶段；Google 产品线整合速度很快。

### 7. Replit Agent

**Why selected**：它不是简单的 coding agent，而是把 Idea → App → Runtime → Deployment 作为完整 agent workflow，代表从 repo-centric SWE 向 idea-to-production 的扩展。

**Main caveat**：平台 50M+ users 是 Replit platform-level claim，不应等价为 Agent-only adoption。

### 8. OpenCode

**Why selected**：独立 adoption signal + 巨大 OSS ecosystem + provider-agnostic open harness + terminal-native workflow，使其成为开源 agent architecture 的关键代表。

**Main caveat**：商业市场规模与企业采用仍显著低于头部商业产品。

### 9. Qoder

**Why selected**：是中国市场最完整的 global-facing agent product family 之一，覆盖 IDE、CLI、Cloud Agents，并体现从 AI IDE 向 agent platform 的演进。

**Main caveat**：6M+ users / 100K+ businesses 主要是 vendor claims，中国市场缺少统一独立 adoption denominator。

### 10. Factory

**Why selected**：代表 enterprise autonomous software engineering / Droids 路线，在 workflow significance 与 enterprise strategic importance 上具有独立性；它使 Top 10 不被 IDE / CLI consumer products 完全占据。

**Main caveat**：独立市场 adoption evidence 不足，是本榜最明显的 Research Judgment override 之一。

## 10. Near-miss Candidates

### 1. TRAE

**Why not Top 10**：产品路线和中国市场重要性都很强，但与 Cursor / Qoder / Antigravity 的 workflow space 重叠较大，独立 adoption evidence 仍不足。

**What it lacks**：更强的独立 global adoption evidence，或更明确的 workflow differentiation。

**What could move it into Top 10**：TRAE Work / agent workspace 获得显著全球采用，或者出现可靠 independent market evidence。

### 2. Kiro

**Why not Top 10**：spec-driven workflow 很强，但 adoption 仍较 Unknown，且 Q Developer → Kiro migration 让市场规模难以与成熟产品直接比较。

**What it lacks**：清晰的 current standalone adoption evidence。

**What could move it into Top 10**：Kiro 获得独立可验证的大规模开发者采用，或 spec-driven workflow 成为明显主流范式。

### 3. OpenHands

**Why not Top 10**：开源 SWE agent platform 很重要，但与 OpenCode 的 open-harness representation、Factory 的 autonomous enterprise representation 存在一定重叠。

**What it lacks**：更强 market adoption / differentiated workflow signal。

**What could move it into Top 10**：Cloud / Enterprise / SDK adoption 明显扩大，或形成更强的 self-hosted agent platform paradigm。

### 4. Augment Code

**Why not Top 10**：large-codebase context/reasoning 路线很强，但独立 market evidence 不足。

**What it lacks**：市场 significance 的可验证性。

**What could move it into Top 10**：enterprise adoption 与 independent market evidence 显著增强。

### 5. JetBrains AI / Junie

**Why not Top 10**：enterprise IDE-native agent 路线重要，且有 ~9% combined JetBrains survey signal，但 capability/workflow differentiation 尚不足以突破最终席位。

**What it lacks**：更强的 autonomous agent differentiation 或独立市场 significance。

**What could move it into Top 10**：Junie 的 long-running / agent-native workflow 在 JetBrains installed base 中形成明显领先，并出现更清晰的 agent-specific adoption evidence。

## 13. Major Evidence Gaps / Unknowns

1. 大多数产品没有统一、独立、同 denominator 的 global active-user data。
2. 中国市场尤其缺乏可比 independent adoption survey。
3. Replit Agent 的 agent-only adoption 与 Replit platform adoption 无法分离。
4. Devin、Qoder、TRAE 等 vendor scale claims 缺少统一 independent validation。
5. Kiro 的 current standalone adoption 仍 Unknown。
6. Factory、Augment、OpenHands、Cline 等 open/enterprise candidates 缺乏与头部相同口径的 market evidence。
7. Public coding-agent benchmarks 的模型、harness、budget、environment 并不统一；不能在 Phase 3 当作绝对 ranking authority。
8. Cursor 2026-08 corporate transition 可能改变长期战略，但短期 capability evidence 尚不能据此推断下降。
